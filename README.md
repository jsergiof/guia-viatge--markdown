
# París

![Torre Eiffel](https://images.unsplash.com/photo-1502602898657-3e91760cbb34?w=800)

París es la capital de Francia. Tiene muchos monumentos y es una ciudad muy visitada.

## Lugares de interés

1. **Torre Eiffel:** es el monumento más famoso.
2. **Museo del Louvre:** es un museo donde está la Mona Lisa.
3. **Notre-Dame:** es una catedral antigua.

## Comida típica

- Croissants
- Baguettes
- Crêpes
- Macarons

La comida francesa es *bastante buena*.

## Qué llevar

- Ropa cómoda
- Zapatos
- Una chaqueta
- Un paraguas

## Información útil

La moneda es el **euro** y el idioma es el francés. Puedes moverte en metro.
